What this is. The HexMosaic floor plan (hexagon / 60°-rhombus / triangle mosaic on the triangular lattice) extruded into a prismatic honeycomb: every tile becomes a column of integer height, drawn under an oblique lattice projection — one height level shifts a vertex by exactly one lattice step along the chosen extrusion direction, so top faces stay the exact 2D tiles and every visible wall is an exact 60°/120° unit rhombus stack (verified live in the ledger). Rendering is a per-atom painter sweep: atom columns are sorted along the extrusion direction and overdrawn back-to-front — occlusion can only happen inside one lattice band along that direction, where the centroid order is total, so the painter order is exact, not a heuristic. Gaps and pit-painted cells draw nothing, so you see the far walls of the columns behind them, like real excavations. Windows work as in HexMosaic: paint or preset chroma columns (flat-shaded for clean GIMP selection), export mask png (white = every visible face of window columns), PNG/JPEG/SVG. Click paints with the selected tool, including raise / lower / set h; pan by dragging, zoom with the wheel. Same seeds → same scene.
