# Circle-fidelity benchmark — code (2026-10-01)

Generated by Claude, 2026-10-01. Findings: `../circle_fidelity_findings_MIRROR.md`.

Needs Python with `numpy`, `scipy`, `matplotlib`, `triangle` (`pip install triangle`, Shewchuk's
mesher, only for the unstructured/graded meshes). `taichi` is needed only for the cross-check.

| file | what it does |
|---|---|
| `gridlib_MIRROR.py` | every grid as (node positions, sparse Laplacian on free nodes, node areas): the app's masked `sq5` / `sq9` / `tri` stencils; mass-lumped P1 finite elements (cotangent Laplacian, mixed-Voronoi lumping) for the fitted meshes: square or triangular lattice + edge triangles, hex shells bent to circles, Penrose + edge triangles, Triangle meshes (uniform / graded) |
| `circle_bench_MIRROR.py` | leapfrog run, exact Bessel-series reference, the two measures (`eps_ang`, `eps_tot`) |
| `xcheck_taichi_MIRROR.py` | runs the app's own `membrane_core_MIRROR.py` (CPU, f64) on a circle and compares fields with this solver |
| `continuum_drum_vs_ball_MIRROR.py` | exact 2D disc vs 3D ball: does a perfect circle repeat each cycle? + radial-mode spacings for D = 2…5 |
| `run1_main_MIRROR.py` … `run7_figure_MIRROR.py` | the runs in the order they were made; `run6` rebuilds every finite-element mesh with the final lumping and **overwrites** their earlier entries, so run all seven in order |
| `r1_whiteboard_sweep_MIRROR.py` | unrelated to the membrane: the same session's R ≠ 1 sweep of the whiteboard relations |

Run order: `python run1_main_MIRROR.py`, then run2 … run7 (each reads/writes the `res_*.pkl` files in
this folder). Whole chain ≈ 5 minutes on a CPU.

Process notes kept on purpose:
- **Lumping bug, fixed.** The first finite-element runs used the textbook 1/3-of-each-triangle mass
  lumping. On a Delaunay-triangulated square lattice that made the node mass depend on which diagonal
  Qhull picked (0.67–1.33 instead of 1), a random medium that scattered waves. Mixed-Voronoi lumping
  (Meyer et al. 2003) gives exactly the app's stencils in the interior: checked row by row, 0 deviant
  rows on both fitted lattices.
- **Home-made DistMesh, dropped.** The compact DistMesh produced slivers (min angle 0.1–13°) and
  bad numbers; replaced by Triangle with a 30° minimum angle.
